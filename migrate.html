Timbered — Data Migration

One-time tool to seed Firestore from WooCommerce data. Run each step once.

Step 1 — Seed products collection

Fetches all published WooCommerce products and writes each to Firestore products/{product_id} with name, image_url, drawing_url, stock_qty, dimensions, and material attributes.

Step 2 — Seed order_phases collection

Fetches all processing WooCommerce orders and writes each line item's tg_phase to Firestore order_phases/{order_id}_{line_item_id}. Only writes items that already have a tg_phase set.
